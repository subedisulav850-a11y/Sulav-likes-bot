# FF Like Sender

Professional Android client for the configured like API.

API endpoint:

`https://like.sulavcodex.com/like?uid={uid}&server_name={region}&key=SulavOp`

## Build on GitHub

1. Create a GitHub repository.
2. Upload this project.
3. Push to `main` or `master`, or manually run **Build FF Like Sender APK** from Actions.
4. Open the workflow run and download the `FFLikeSender-debug` artifact.

## Notes

- The app uses Android's standard HTTPS networking.
- It does not require root.
- API availability and response format are controlled by the server.
- Use only with an API/server you are authorized to access.
